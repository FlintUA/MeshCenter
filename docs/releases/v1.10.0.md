# MeshCenter v1.10.0

Range: `v1.9.0..main` (`3b71169`), PRs #331–#345.

**This release can be applied from the Updates card.** `requirements.txt`, `adapters/meshtastic/requirements.txt`, `install.sh` and the deploy/installer files are unchanged since v1.9.0, so no package install or manual step is needed (v1.9.0 required a manual upgrade). Open **Workspace → System → Updates**, press **Check now**, then **Update** (it appears once v1.10.0 is published), or `git fetch --tags && git merge --ff-only origin/main` followed by `sudo systemctl restart meshcenter.service`. As with any update, keep a copy of `data/` and `config.py`.

## Messaging

- Every new message now carries a date: today shows `18:36`, yesterday `yesterday 18:36`, earlier this year `08.10 18:36`, older `08.10.2025 18:36` — in message bubbles and in the chat list's last-message time, following the interface language (#338)
- Opening a chat with unread messages lands on the first unread one, marked by an "Unread messages (N)" divider that stays while the chat is open; a floating ↓ button returns you to the latest message whenever you are not at the bottom; new incoming messages only auto-scroll when you were already at the bottom (#338)
- The chat list is now sorted by the real time of the last message across days, instead of by the time of day, so yesterday 23:00 no longer sorts above today 09:00 (#338)
- Click a message to scroll the node list to its sender's card and highlight it for two seconds (your own messages highlight your own node); the same action is in the message's ⋮ menu as "Sender's node". Clicking a reply quote scrolls to the original message, or tells you it is not loaded. The highlight looks like a selected card and fades out (#339, #340)
- Dark theme: the sender name, time, delivery ticks and reply quote inside your own (light-blue) message bubbles are readable again; the failed state stays clearly red (#341)

## Nodes & map

- The node list has a ⚙ button with a sort (last heard, A–Z, distance, hops, favorites first) and filters (favorites only, ignored only, hide offline, heard directly only, hide infrastructure, known key only), shown as removable chips and remembered in the browser. The old "favorites only" / "ignored only" toggles moved here from the Toolkit tab (#338)
- Ignored nodes are now hidden from the node list by default; turn on the "Ignored only" filter to see them (#338)
- Map and node list now work on a "click looks, actions are explicit" model: clicking a node on the map selects it (marker, dashed line, header distance/bearing, card scrolled into view and flashed) without opening a chat; double-click opens the direct message; right-click (long-press on touch) opens one context menu with an info header (name, ID, role, last activity, hops, SNR, battery, distance, azimuth) and the actions — Message, Favorite, Ignore, Waypoint here, Center, Request key, telemetry, position, traceroute, Set/Clear reference, Copy coordinates, Details. Right-click on empty map still creates a waypoint; Esc closes the menu, a second Esc clears the selection (#342, #343)
- In the node list, a click selects the node (and centers the map when it is open); the new 💬 button on each card, or a double-click, opens the direct message (#342)
- Ignoring a node from the map or card shows "Node ignored — hidden from the list" with an Undo button, and the node's map marker follows the same rule as the list (#343)
- The reference point on the map is clickable: a reference node behaves like any node (its menu offers "Clear reference point"), a plain location opens a menu with Copy coordinates, Change reference point and Waypoint here. The reference-location headers use the 📌 pushpin (#343, #344, #345)
- Selecting a node anywhere — node list, map, chat list or the 💬 button — now scrolls it into view in both the chat list and the node list with the same smooth, centered scroll (it used to highlight the chat-list entry without scrolling to it) (#343, #344)

## Radio reliability

- Serial hot-reconnect: unplugging and replugging the radio's USB cable, a `/dev/ttyACM` renumbering, starting MeshCenter with no radio attached, and a power cycle are all recovered from automatically without restarting the service. The radio's identity is re-verified before the link resumes, and a different radio appearing on the port is never silently adopted — the listener stays halted and the System Log says so (#331)
- A 24-hour passive measurement confirmed the occasional quiet-period listener restart is pre-existing and not caused by the hot-reconnect work (documented as KI-009) (#332, #334)

## Security

- CSRF auto-recovery: after a re-login (in another tab, or after a restart) an older open tab no longer fails sends and "delete locally" with a raw "CSRF token missing or invalid" — it fetches the current token from the new `GET /api/auth/csrf` and retries the rejected request once; if that fails it shows the usual "reload" notice, once. CSRF errors are translated in the send and delete dialogs (#339)
- Security headers on every response (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`); Wi-Fi SSID validation (length, leading `-`, control characters) and stricter JSON-body checks on the system routes; an out-of-range waypoint expiry is rejected instead of crashing; and a startup warning when a leftover `data/initial_password.txt` from v1.8.x is still on disk (#335)
- A CI check now blocks any new inline `onclick=…`-style handler built from a template literal (the shape behind the earlier XSS fixes), with an inventory of the remaining ones (#333)

## Upgrade notes

- **The Updates card works for this release** — no dependency or installer changes.
- **Ignored nodes are now hidden from the node list by default.** Turn on the "Ignored only" filter (⚙ next to the node search) to see and restore them. Any "favorites only" / "ignored only" choice you had in the Toolkit tab is carried over once into the new filters.
- **Clicking a node (on the map or in the list) no longer opens the chat.** Use the 💬 button, double-click the node, or "Message" in the map menu.
- **If a warning about `initial_password.txt` appears** (System Log and notifications), follow it: if the password is still the one that file contains, change it in Settings → Security and delete the file. The file is never removed automatically.
- **New messages store a date; older messages keep showing the time only.** Nothing is converted or lost.

## Known limitations

- If a *different* radio is plugged into the port after an unplug, MeshCenter halts and asks you to confirm (see "A different radio was connected" in the User Guide). This path is covered by automated tests but has not been verified live with a second physical radio.
- Touch long-press on the map (node menu, waypoint) is implemented but has not been verified on a real phone; the full mobile layout is still pending.
- Bluetooth (BLE) is send-only — nothing is received while it is the active transport. TCP has a narrower receive scope than serial: no routing acknowledgements, no remote waypoint deletion, and an event captured while the link is down can be lost.
- Message and chat-list times use a fixed 24-hour format and do not follow the 12h/24h toggle (KI-007).
- During quiet operation the serial listener can occasionally restart on its own, with a brief "listener down" blip in the health display (KI-009: measured over 24 hours, pre-existing and cosmetic, not caused by the hot-reconnect work).
- USB MJPEG passthrough has not been live-verified against a real MJPEG-capable camera.
- The README's screenshots are from v1.5.0 and do not show the current layout.
