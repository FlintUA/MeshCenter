# MeshCenter v1.13.3

Range: `v1.13.2..main`, one fix.

`requirements.txt`, `adapters/meshtastic/requirements.txt`, the systemd unit, the sudoers templates, the udev rule, the privileged helper scripts, `gunicorn.conf.py`, `wsgi.py`, `install.sh` and `meshcenter-firstboot.sh` are unchanged since v1.13.2, so nothing is blocked and no manual step is needed. Open **Workspace → System → Updates**, press **Check now**, then **Update** (or **Roll back** to v1.13.2 afterwards). Reload the page once with Ctrl+F5 so the browser takes the new page. Docker users rebuild the image (`meshcenter:1.13.3`).

## Fix: the "Sign out everywhere" button was missing in v1.13.2

The v1.13.2 notes and the README describe a **Sign out everywhere** button (Security card on the System page), but the v1.13.2 page did not contain it: the button block was lost in a merge while the server side (`POST /api/auth/logout_all`), the click handler and the translations were all there. It is back, exactly as described in the v1.13.2 notes: it ends every signed-in browser on every device, this one included, and every open camera stream, after a confirmation. **Sign out** next to it still ends only the session of the browser you press it in.

Nothing else changed: the page differs from v1.13.2 by that one block. A new test makes the build fail if the page loses this button again, and a second test checks that every element a script attaches a click or change handler to exists in the page.

## Known issues

Unchanged from v1.13.2 (see its notes). The phone layout work (the System, Settings and About menus cannot be opened on a phone yet) is planned for v1.13.4.
