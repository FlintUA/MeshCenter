# MeshCenter v1.13.5

Range: `v1.13.4..main`, four changes: the rest of the phone layout (System, Settings, About, Nodes, Base, Node Manager), a calmer Updates card, and a faster "Busy" chip.

`requirements.txt`, `adapters/meshtastic/requirements.txt`, the systemd unit, the sudoers templates, the udev rule, the privileged helper scripts, `gunicorn.conf.py`, `wsgi.py`, `install.sh` and `meshcenter-firstboot.sh` are unchanged since v1.13.4, so nothing is blocked and no manual step is needed. Open **Workspace → System → Updates**, press **Check now**, then **Update** (or **Roll back** to v1.13.4 afterwards). Reload the page once with Ctrl+F5 so the browser takes the new page. Docker users rebuild the image (`meshcenter:1.13.5`).

## Phone layout (MOB2-D, E, F)

All size and text changes apply on a narrow screen (768 px and below) only; a wide screen is laid out exactly as before.

- **System, Settings and About:** 44 px buttons, rows and tabs, 16 px fields (iOS no longer zooms the page when a field is focused), 11 px minimum text, and the Settings select no longer sticks out of the screen. The **Workspace** menu has a **Status** block at the top with the version, CPU, RAM, temperature and uptime, which the phone dock does not show.
- **Nodes:** the list shows the first 60 nodes (your own node first, then favourites, then the most recently heard; another sort keeps your order) with a **Show more** button for the next 60. A search covers all nodes, and a node you select or jump to from a message is always shown. Node cards have 44 px targets and readable text; the small pills (distance, key, node ID) keep their look and get a larger tap area.
- **Nodes header and filters:** the search field, clear and gear buttons have gaps and 44 px targets. The **Sort and filters** popover opens below the row, fits between the header and the dock (it scrolls inside, with a visible scrollbar, on a short screen such as 320x568), and closes with the gear, a tap outside or Esc.
- **Base and Node Manager:** 44 px buttons and 11 px text; the **Environment** and **Power** chart tiles are no longer light in the dark theme (this fix applies to every screen width; the light theme is unchanged).

## Updates card and Busy chip (UX1, BUSY1)

- Pressing **Update** shows **Checking...** at once on the status line and the button, instead of nothing for several seconds while the version is verified. The manual rollback command is collapsed under **Manual command**, and **Roll back** has its own section, no longer next to **Check now** and **Update**.
- After a radio command (traceroute, node scan, sending) the header chip no longer says a plain **Busy** for about 14 seconds once the listener is back: a stale "Busy" or "Starting" is recomputed from the live state.

## Known issues

Unchanged from v1.13.4 (see its notes). Leftovers planned for later: the tablet widths (769 to 1100 px), the installation ID text on the System page (15 px high, copy-only), a few 10 px labels on the Base page and the dock chevron, the toggles are 24 px boxes inside 44 px labels, the Nodes pane and Node Manager were checked on a phone-sized sandbox and an iPhone SE but not on every device, and Trace route over a TCP radio is not available yet.
