# MeshCenter v1.13.7

Range: `v1.13.6..main`. Ten changes: automatic KEY_REQUEST retries for MCAttach, a counters row in the Nodes header, a one-rule "heard directly" filter, decoding of serial names and waypoints, phone layout leftovers, new README screenshots and a clearer Docker update block.

`requirements.txt`, `adapters/meshtastic/requirements.txt`, the systemd unit, the sudoers templates, the udev rule, the privileged helper scripts, `gunicorn.conf.py`, `wsgi.py`, `install.sh` and `meshcenter-firstboot.sh` are unchanged since v1.13.6, so nothing is blocked and no manual step is needed. Open **Workspace > System > Updates**, press **Check now**, then **Update** (or **Roll back** to v1.13.6 afterwards). Reload the page once with Ctrl+F5 so the browser takes the new page. Docker users rebuild the image (`meshcenter:1.13.7`).

## MCAttach: automatic KEY_REQUEST retries

- **Retries:** after you request a contact's key, MeshCenter re-sends the same signed request 10 minutes, 30 minutes and 2 hours later (4 attempts in total), then waits 6 hours for the answer and gives up. The Files card shows "Waiting for response - attempt 2 of 4, next in 8 min" with a **Stop requests** button.
- **Limits unchanged:** every attempt obeys the per-contact 10 minute interval and the 12 per hour automatic request budget, so retries never add load beyond what a manual request could do. There is no protocol change.
- **It ends by itself** when the contact's key arrives (the announce), when the node is no longer in the node list, or when you press **Stop requests**. After the last wait the state is **No answer** and **Request again** is offered. A retry that cannot go out because the radio is released, busy or not connected is postponed by one minute and does not use an attempt.
- **Survives a restart:** the series is stored in the database.
- **Database schema 18:** the MCAttach database (`data/mca/attachments.db`) migrates from schema 17 to 18 on the first start (two new columns in `mca_key_exchange_contact_state`, added atomically). The **Roll back** button goes back to the previous code, not to the previous schema. The v1.13.6 code runs on a schema 18 database: on start it sees a newer schema and runs the built-in down migration, which drops the two columns (needs SQLite 3.35 or newer, which every supported system has). The only thing lost is a running retry series; contacts, keys, transfers and all other data stay untouched.
- Checked live between two nodes: attempt 1 lost while the target radio was released, attempt 2 answered with the announce after Reconnect and ended the series, and Stop requests ended a running series and kept the 10 minute interval.

## Nodes header: counters

- The empty header row of the Nodes list now shows the number of nodes (`12 of 638` while a search or filter is active), `N online` (heard in the last 2 hours, the same rule as "Hide offline") and `N direct`. **Online** and **direct** are buttons that switch the matching filter; a small x clears the search and all filters. The row stays at the top while you scroll.
- The labels shrink to `84 + 7` only when the full text really does not fit the row (measured each time, so page zoom and large text sizes no longer force the short form). Touch screens get 44 px tap areas.
- **"Heard directly" is one rule now:** a node counts as heard directly when its own packet arrived without a relay in the last 24 hours (nodes without that record fall back to 0 hops and heard in the last 24 hours). The filter and the counter use the same rule; the filter is renamed "Heard directly (last 24 h)".

## Serial names and waypoints

- Waypoint names and descriptions and NodeInfo long and short names received over the serial listener are decoded strictly (apostrophes, quotes, backslashes, line breaks, emoji and Cyrillic come out as the TCP link delivers them, and a name can no longer forge the next field of the listen line). Stored history is not rewritten.

## Phone layout

- Installation ID, Base weather labels, the dock chevron and the toggle boxes now meet the 44 px target and 11 to 14 px text sizes on a phone.

## Documentation

- **README screenshots** are new (chats, map, Files, camera, devices, system, phone) and made from invented demo data; the generator is `scripts/demo_screenshots/` (demo server plus capture script), so they can be retaken without real node names.
- **Docker update:** a copy-paste block (verify, load, set the version, `up -d`), a warning to load the image first and one path used everywhere.
- **Repository:** `.claude/launch.json` is no longer tracked and `.claude/` is ignored.
