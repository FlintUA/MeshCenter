# MCAttach Relay для Hostinger

Версия: 0.1.0 pilot

Это самостоятельный PHP Relay для временного хранения зашифрованных объектов
MCA/1. Он предназначен для поддомена `mcattach.elektroniker.help` и не зависит
от WordPress.

В этот пакет входит серверная часть Relay и HTTP API. Вкладка `Файлы`,
локальное шифрование, выбор адресатов и отправка короткого MCA-кода относятся
к клиенту MeshCenter и подключаются к этому API следующим этапом.

## Важная граница

Relay не шифрует пользовательские файлы и не знает их исходные имена. Перед
upload MeshCenter обязан:

1. зашифровать файл и манифест;
2. создать recipient envelope;
3. вычислить digest каждого ciphertext chunk;
4. создать `transfer_id` с 128 битами случайности;
5. передавать Relay только ciphertext и receipt hashes.

Версия 0.1.0 является пилотной серверной реализацией. До публичного сервиса
необходимы независимый security review, нагрузочные тесты, privacy notice,
правила допустимого использования и процесс реагирования на злоупотребления.

## Требования

- PHP 8.2 или новее;
- PDO MySQL;
- Sodium;
- JSON;
- отдельная база MySQL;
- действующий HTTPS для поддомена.

Установщик проверяет эти требования до записи конфигурации.

## Установка на Hostinger

1. В hPanel создай отдельную базу MySQL и пользователя базы.
2. Сохрани имя базы, имя пользователя, пароль и MySQL hostname.
3. Открой файловый менеджер сайта `mcattach.elektroniker.help`.
4. Перейди в `public_html`.
5. Загрузи ZIP-пакет и распакуй его непосредственно в `public_html`.
6. Убедись, что `index.php` и `.htaccess` находятся прямо в `public_html`, а не
   во вложенной папке.
7. Открой `https://mcattach.elektroniker.help/setup`.
8. Вставь ключ из локального файла `SETUP_KEY.txt` и реквизиты MySQL.
9. После успеха немедленно сохрани показанный `upload access token`.
10. Проверь `https://mcattach.elektroniker.help/health` и `/v1/info`.
11. Только после успешной проверки удали стандартный `default.php` Hostinger.

Официальные инструкции Hostinger:

- создание MySQL базы: <https://www.hostinger.com/support/1583542-how-to-create-a-new-mysql-database-in-hostinger/>;
- настройка Cron: <https://www.hostinger.com/support/1583465-how-to-set-up-a-cron-job-at-hostinger/>.

Установщик создаёт рядом с `public_html` каталог `mcattach_private`. В нём
хранятся конфигурация, ключ Relay и ciphertext. Каталог не должен переноситься
в `public_html`.

## Автоматическая очистка

Создай ежедневную Cron-задачу с CLI-командой PHP для файла:

```text
public_html/bin/cleanup.php
```

Полный абсолютный путь зависит от аккаунта Hostinger. Используй путь,
показанный hPanel. Скрипт работает только через PHP CLI и закрыт от HTTP.

Relay также выполняет редкую opportunistic cleanup при обычных запросах, но
она не заменяет ежедневную Cron-задачу.

## Устойчивость к обрыву сети

MeshCenter должен сохранять `upload_id`, `upload_token` и `revoke_token` в
локальной очереди до завершения передачи. Через
`GET /v1/uploads/{upload_id}` он получает список уже принятых частей и после
восстановления сети отправляет только отсутствующие chunks и manifest.

Сессия незавершённой загрузки действует 6 часов. Hard expiry файла начинается
только после успешного commit. Поэтому время без сети до начала или во время
загрузки не сокращает 72-часовой срок доступности готового файла.

## Значения пилотной конфигурации

- максимум ciphertext одного объекта: 6 MiB;
- рекомендуемый максимум исходного файла в MeshCenter: 5 MiB;
- максимальный chunk: 300 KiB;
- максимум chunks: 64;
- upload session: 6 часов;
- hard expiry: максимум 72 часа;
- grace после подтверждения всех получателей: 1 час по умолчанию;
- tombstone после revoke или expiry: 7 дней;
- внутренняя квота Relay: 10 GiB;
- anonymous upload: выключен.

## Секреты

- Не публикуй `upload access token`.
- Не передавай токены через URL или query string.
- Не размещай содержимое `mcattach_private` в публичном каталоге.
- Не добавляй `config.php`, upload token или database password в Git.
- Не публикуй скриншоты hPanel с паролями и токенами.

## Обновление

Перед обновлением сохрани резервную копию:

- каталога `mcattach_private`;
- таблиц `mca_*` в MySQL.

Не запускай `/setup` повторно и не заменяй приватный `config.php`. Обновляемый
пакет должен заменять только программные файлы внутри `public_html`.
